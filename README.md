# Network Packet Sniffing and Analysis

[![License](https://img.shields.io/badge/license-CC%20BY%204.0-blue?style=flat-square)](LICENSE)

## Objective
Capture and analyze network traffic to identify:
- Credentials
- Suspicous activity

## Tools Used
- [Wireshark](https://www.wireshark.org/) – Packet capture and analysis.
- [DVWA](https://github.com/digininja/DVWA) (Damn Vulnerable Web Application) – Vulnerable web application for security testing.

## Conclusion

This analysis demonstrates how dangerous it is to transmit sensitive data over HTTP without encryption.  
- Credentials and files were exposed in plaintext.

Recommendation:  
Always use HTTPS and strong input validation to prevent these vulnerabilities.
